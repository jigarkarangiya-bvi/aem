# Hero V1 Block

The Hero V1 block creates an elegant, full-width image hero with a refined text overlay, inspired by high-end furniture retailers. It features a classic serif title, a sharp uppercase subtitle, and a solid black CTA button.

## Google Drive Authoring

To use this block, create a single-cell table in your Google Document:

| Hero-v1 |
| :--- |
| **[Insert Hero Image Here]**<br>NEW STYLES ADDED<br># The Ellington Collection<br>[SHOP NOW](https://example.com) |

### Authoring Rules:
1. **First Line:** The image. This MUST be the very first thing in the cell.
2. **Second Line:** The Subtitle (e.g. "NEW STYLES ADDED"). This should be standard text, no formatting.
3. **Third Line:** The Title (e.g. "The Ellington Collection"). This should be an H1 or H2 heading.
4. **Fourth Line:** The Button (e.g. "SHOP NOW"). This must be a standard hyperlink.

### Alignment Variants
By default, the text and gradient overlay are aligned to the **Left**. You can dynamically change this by adding a modifier to the table header in Google Drive!
*   **Right Aligned:** Name the table header `Hero-v1 (Right)`. The text will snap to the right, and the gradient overlay will flip to the right side!
*   **Center Aligned:** Name the table header `Hero-v1 (Center)`. The text will be perfectly centered, and a circular radial gradient will be applied to the center of the image!

*Note: The text will automatically be styled with the elegant serif fonts and sharp black button design, and will position itself cleanly based on the variant you choose.*
