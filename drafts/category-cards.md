# Category Navigation Section

This document describes how to author the new horizontal category navigation cards (e.g., Sectionals, Sofas, Chairs) you requested, based on the Interior Define screenshot.

Since this uses the exact same slider logic as our existing `cards` block, you just need to author it as a standard Cards block but add the `(Category)` variant in the block heading.

### How to Author in Google Drive:

1. Create a Table with 2 columns.
2. In the top merged header row, type: **Cards (Category)**
3. For each subsequent row, place the category image in the left column and the category name in the right column.
