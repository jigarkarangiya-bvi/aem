# Brand List Block

The Brand List block allows you to showcase a horizontal grid of square images that link out to different brands or collections. It natively supports touch-swiping on mobile and neatly distributes the images across the page on desktop.

## Google Drive Authoring

To use this block, simply create a table with the header `Brand-list`. Each cell inside the table represents one card in the grid.

### 1. Title and Disclaimer
The Brand List block is usually paired with a title and a disclaimer. Simply type a standard Heading above the block, and a standard paragraph below the block!

### Authoring Rules:
1. **Grid Cells:** You can structure your Google Docs table with 1 column, 2 columns, or as many as you want! The code will automatically find all the images.
2. **Contents:** Inside each cell, place exactly two things:
    *   **The Image:** A square logo or brand lifestyle image.
    *   **The Link:** A hyperlink to where that brand should go.
3. **Empty Cells are Fine:** If you leave a cell empty, the code will just safely ignore it!
4. **No text allowed:** Do not add descriptive text inside the cell, as the javascript will hide it to create the clean square grid.

*Note: On desktop, the grid will try to squeeze up to 9 items in a single row just like the West Elm design. On mobile, it will become a fluid, swipeable carousel!*
