# Columns Block

The Columns block creates a beautiful, spacious 50/50 split layout. It is perfect for pairing elegant typography with high-quality photography, utilizing the same premium serif fonts and generous spacing found throughout the site.

## Google Drive Authoring

To use this block, create a two-column table in your Google Document:

| Columns | |
| :--- | :--- |
| ## Experience the Comfort<br><br>Learn about our premium fabrics, modular design, and lifetime guarantee that makes our furniture perfect for any home.<br><br>**[FIND A STORE](https://example.com)** | **[Insert High-Quality Photo Here]** |

### Authoring Rules:
1. **Left Cell (Content):** Put your text here. 
    *   Use a Heading 2 (`##`) for the title so it picks up the elegant serif font.
    *   Add a standard paragraph for the description.
    *   Add a standard link at the bottom. **Crucial Step:** You MUST make the link **Bold** (CTRL+B / CMD+B). AEM uses bold formatting to know that it should transform the plain link into our new, unified sharp black button!
2. **Right Cell (Media):** Paste your high-resolution image here. It will automatically fill the height of the column and crop perfectly.

### Alignment Variants
By default, the first cell is on the left and the second cell is on the right. You can reverse this layout on desktop!
*   **Reversed:** Name the table header `Columns (Reverse)`. The image and text will swap sides on desktop, allowing you to create beautiful zig-zag "checkerboard" layouts when stacking multiple column blocks on top of each other!
